# 84PAD Builder — isolated incubation checkpoint

This path is **not Core code**. This GitHub branch is a tracking-only staging checkpoint for an independently distributed 84PAD Builder plugin. Do **not** merge the plugin into Core.

**Builder:** v0.1.0-dev, created 2026-10-22; publisher ParmTech.

The full source package and single-file functional editor demo are supplied as separate downloadable files in the Builder development conversation. Source is not yet in an independent GitHub repository. GitHub-connected tooling currently does not support creating a new repository; the intended repository is `manbir6-ux/84pad-builder` after setup.

Working prototype includes 9 element types; nested drag/drop; selection, inspector, layer tree; responsive canvases; undo/redo; pages; local autosave; JSON import/export; HTML export/preview.

**Do not describe as a Core-installable plugin.** Core C08–C12 discovery/activation/contracts are unfinished; the manifest is a draft. No authenticated persistence, publishing, revisioning or production release exists yet.

See [Builder tracking issue #22](https://github.com/manbir6-ux/84pad-core/issues/22) and `docs/PROGRESS.md` in the downloadable source bundle for implementation details and test evidence.

Next: browser QA, independent repo publication, Core contract adapter after C08–C12, persistent drafts and secure publishing.
